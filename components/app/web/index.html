How these sources connect The clock, the spell and the drawing

The Rust browser loop is the clock. It keeps each X_eTaL program loaded and sends input and time messages. The spell program imports its X_eTaL libraries, updates its own state and returns geometry or terrain commands. Rust uploads the geometry to WebGPU and applies terrain changes to the shared visible/collision mesh.

For Ribbon: hold 2 → Rust input adapter → ribbon.xtl → Ribbon.xtl and RibbonSurface.xtl → typed triangle data → Rust renderer → screen. Releasing 2 sends a new message; the library throws the head while its saved path becomes the tail.

The source panels show the real embedded program text. They are viewers; the running programs keep their own state. Each spell has a separate evaluator in the same WASM app, currently on the browser main thread. Follow library calls to their source and API reference.
