# Surface component

Smooth surface construction and mesh contracts.

This component is an independent Cargo workspace containing `xetal-world-surface`.
It validates typed mesh buffers and adapts Scene triangle arrays and one-based
indexed X_eTaL arrays, with an explicit f32 conversion policy. See the
[mesh contract](../../docs/mesh-contract.md), [architecture](../../docs/architecture.md)
and [development](../../docs/development.md).
