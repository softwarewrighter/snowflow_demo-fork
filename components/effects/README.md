# Effects

This independent Rust 2024 workspace provides the native Bloom host adapter and
a reusable bounded instanced-particle renderer. X_eTaL source under world/libs
owns spell timing, particle kinematics, crater shape and retention. The native
adapter reads typed numeric publications; the renderer draws procedural flakes
without texture assets. See [Bloom](../../docs/bloom.md) and the
[library reference](../../docs/libraries.md).
