# Original Snowflow source

`snowflow-original/` preserves every tracked file from upstream reference commit
`545039733b74eec742862f161990142c7ca7c7ec`, including its README, lockfile,
shaders and original MIT license. [The archive manifest](../docs/archive.lock.json)
records each file's SHA-256. Do not modify these files to develop the new app.

The original README is also available as [orig-README.md](../orig-README.md).
The archived application retains its original npm/Vite commands; run them from
`archive/snowflow-original/`. Installing dependencies requires network access.
Archive verification does not execute or benchmark the original application.
