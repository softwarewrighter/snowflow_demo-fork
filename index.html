How these sources connect The clock, the spell and the drawing

App.xtl is the application entrypoint. It imports Spells.xtl, which chooses the spell libraries and maps keys to actions. Rust loads this one program and sends it input, time and physics facts. The program returns typed geometry, sound commands, controls and source metadata for Rust to display.

For Ribbon: hold 2 → App.xtl → Spells.xtl → Ribbon.xtl and RibbonSurface.xtl → typed triangle data → Rust renderer → screen. Releasing 2 changes the library state to throw the stream. These sources run in one persistent evaluator on the browser main thread; worker migration remains future work. Follow library calls to the API and source reference.
